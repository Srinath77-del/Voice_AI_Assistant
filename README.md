# Voice AI Assistant

A simple Voice AI Assistant web application that allows users to interact with an AI system using both text and voice input. The project demonstrates how speech recognition, web development, and AI APIs can be integrated to build an interactive assistant.

---

## Features

- Text-based question input
- Voice input using microphone
- Speech-to-text processing
- AI-powered response generation
- Simple web interface
- Real-time response display

---

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SpeechRecognition
- Whisper (for speech-to-text)
- Groq API (for AI responses)
